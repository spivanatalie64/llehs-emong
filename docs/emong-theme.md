# EMONG Theme Notes

EMONG should feel like Cinnamon at a glance: grounded panel chrome, clear app
launching surfaces, and a calm accent system, while retaining GNOME-like
workflow behavior.

## Palette

* Base: graphite / warm gray
* Surface: slightly lifted neutral panels
* Accent: a single strong cyan or mint line
* Warning: saturated amber
* Destructive: muted red

## Shape Language

* Small corner radii on panels and menus
* Thin borders only where they improve readability
* Shadows should separate layers, not create depth noise

## First Theme Targets

1. Top panel
2. App menu / launcher
3. Notifications
4. Settings chrome
5. Login / lock visuals
